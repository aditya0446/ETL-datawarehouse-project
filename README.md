# ETL Data Warehouse Project

This project implements an ETL data warehouse pipeline by integrating data from multiple sources, including CRM and ERP systems, into a centralized reporting model.

## Project Highlights
- Data ingestion from CRM and ERP sources
- ETL workflow across bronze, silver, and gold layers
- Data cleaning, transformation, and standardization using SQL
- Gold layer designed with a star schema for efficient analytical reporting

## Tech Stack
- SQL
- SQL-based ETL and data warehouse development

## Data Layers
- Bronze: Raw source data
- Silver: Cleaned and transformed data
- Gold: Analytics-ready data using star schema

## Objective
To build a scalable and reliable data warehouse that supports business reporting and data-driven decision-making.
